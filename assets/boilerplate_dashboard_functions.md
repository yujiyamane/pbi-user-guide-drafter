## Dashboard Functions

The following functions are available within the Power BI Service interface for this dashboard.

| Function | Location | Description |
|---|---|---|
| Navigation Pane | Left sidebar | Expand/collapse to browse workspaces, dashboards, reports and datasets |
| File | Top menu | Save a copy, print, or embed the report |
| Share | Top menu | Share the report link with other users |
| Export | Top menu | Export report data to Excel or PDF |
| Chat in Teams | Top menu | Open the report directly in a Microsoft Teams conversation |
| Bookmarks | Top menu > View | Save and restore specific filter states or views of the report |
| View | Top menu | Toggle full screen (F11), fit to page, fit to width, or actual size |
| Refresh | Top right | Manually refresh the report data |
| Comment | Top right | Add comments or annotations to the report |
| Favourite | Top right | Add the report to your Power BI favourites list |
| F11 | Keyboard | Toggle full-screen mode |
