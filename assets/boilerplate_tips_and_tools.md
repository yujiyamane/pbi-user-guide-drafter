## Other Useful Tips and Tools

### Tooltips
Hover over any visual element (bar, line, data point, KPI card) to see a tooltip with additional detail, such as exact values, percentage breakdowns, or contextual information not shown in the visual itself.

### Date Stamp
The date stamp displayed on the dashboard indicates when the underlying data was last refreshed. Always check this to confirm you are viewing current data before making decisions.

### Reset Options
To clear all active filters and slicers and return the report to its default view:
1. Click the **Reset to default** button (circular arrow icon) in the top-right toolbar, or
2. Use the **Bookmarks** panel to navigate back to a saved default view if one has been configured.
